## Identified Research Gap

Existing studies demonstrate the effectiveness of DLP, UEBA, anomaly detection and automated data classification. However, the selected literature shows limited integration of these capabilities within a single adaptive enterprise DLP framework.

The proposed research therefore combines:

**Endpoint Monitoring → UEBA Risk Scoring → Context-Aware Data Classification → DLP Decision → Allow / Warn / Block**

This approach aims to improve proactive data leakage prevention while reducing false-positive alerts for legitimate data transfers.
